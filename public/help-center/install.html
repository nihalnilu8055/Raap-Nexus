Install Raap Nexus

Windows installer, macOS package, running from source on any system, and the Android app. No admin rights are needed on Windows.

Before you start

  • A computer running Windows 10 or 11 (64-bit), macOS 11 or newer, or Linux.
  • At least one way to reach an AI model: an AI command-line tool that is signed in on this computer, or a model address and key. You can set this up after installing (AI agents).

Windows

  1. Download the installer, RaapNexus-Setup-<version>.exe, from Techlogica.
  2. Double-click it. It installs for your user only, so it needs no administrator rights, and it brings its own Python runtime.
  3. Choose whether to add a desktop shortcut and whether to start when I sign in. Keep that option on if you use schedules (Automations) because they only run while Raap Nexus is running.
  4. Finish. Raap Nexus opens in your browser at http://localhost:8787.
Careful

The installer is not code-signed yet, so Windows may show an unknown-publisher message. If you downloaded it from Techlogica, choose More info and then Run anyway.

macOS

  1. Download RaapNexus-<version>-mac.zip and unzip it.
  2. Right-click Install Raap Nexus.command and choose Open. It copies Raap Nexus.app to Applications.
  3. Open the app. It needs Python 3.9 or newer and tells you if it is missing.

The package is not signed by Apple, which is why you right-click the first time. A READ ME FIRST file inside the zip explains the same.

Any system, from source

You only need Python 3.9 or newer (no extra packages, no build step).

SystemStart it with
Windowsdouble-click start.bat
macOS and Linux./start.sh
Anywherepython raapnexus.py

Useful options: --port 9000, --host 0.0.0.0 (reachable from your network, off by default), --data <folder>, --no-browser. Run python raapnexus.py stop to stop it.

Android

The Android app is a window onto the copy of Raap Nexus that runs on your computer. Install the .apk from Techlogica, then give it your computer's address (Use it on your phone).

Where your data lives

Installed copies keep your data outside the program folder, so updates and reinstalls never touch it: %APPDATA%\Raap Nexus on Windows and ~/Library/Application Support/Raap Nexus on macOS. The uninstaller asks before it touches your data.

Tip

Opening Raap Nexus again while it is running just opens the running copy. To stop it, use Stop Raap Nexus in the Start menu (Windows) or python raapnexus.py stop.
