Connector types

MCP servers, SQLite files, folders, SQL databases, OData, REST, GraphQL, Tally and ready-made products.

Local folders, SQLite files and MCP servers work without registering. More types are issued by Techlogica once your computer is registered (Register with Techlogica).

TypeUse it forYou enter
Remote MCP serverYour ERP's MCP endpoint, or any MCP serviceThe URL (starting with http:// or https://), an optional access token, optional extra headers
Local MCP serverA tool that runs on this computerA command, for example npx -y some-mcp-server, and its arguments
SQLite databaseA local .db file, read-only SQLThe file path
Folder of filesExcel, Word, PDF, CSV, text, JSON and Markdown filesThe folder. The AI can list, read and search files inside this folder only
SQL Server, MySQL, PostgreSQLCompany databasesServer, port, database, a read-only user (a connection string such as postgresql://user:password@host:5432/database also works)
OracleOracle Database 12c or newer, no Oracle client neededHost, port and service name, or a full connect string
SAP HANAHANA Cloud (port 443) or on premiseHost, port, user. HANA needs SAP's own driver, which Raap Nexus can download after you accept its licence
ODataAn OData serviceThe service root, the address that ends where $metadata starts. Only GET requests are sent
REST APIAny JSON APIA base address, a list of endpoints with sample payloads, and a bearer token, API key or user name. PUT, PATCH and DELETE are never sent
GraphQLA GraphQL endpointThe address and saved queries (queries only)
TallyTallyPrime on this networkThe address, usually http://127.0.0.1:9000

Tally in two steps

  1. Open TallyPrime with the company loaded.
  2. Go to Help (F1) > Settings > Connectivity > Client/Server configuration and set TallyPrime acts as to Server or Both (port 9000).

Raap Nexus only sends read (export) requests to Tally.

Which software is this?

On a connector you can say which software it belongs to. If Techlogica already has a business profile for that software, it is linked and no (token-costing) study is needed. If it has none yet, and you agree to share (What is shared with Techlogica), only the names of tables and columns are sent, never rows, host names or passwords.

Report-based software

Some software answers through its own report files (FastReport, ActiveReports, JasperStarter and similar). Under the connector's Reports you say which reporting tool it uses. Raap Nexus lists the report files, so the assistant can find the right one, read its rules and run it. The list stays on this computer.
