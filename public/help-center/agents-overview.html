AI agents and models

An agent is any AI you want to work with: a CLI on this computer, or any model reachable by a web address and key.

What an agent is

Raap Nexus does not have an AI of its own. It lets you plug in the AIs you already use. Every one of them is called an agent, and there are two kinds:

  • CLI agents are AI command-line tools installed and signed in on this computer: Claude Code, Codex, Gemini, Ollama, Cursor and others. There are no API keys to paste.
  • URL agents are any model reachable by a web address with a key: OpenAI, Anthropic, OpenRouter, Groq or a local server.

The agent list

Open Settings > AI > Agents & models. Each agent has a card with a switch, Test, Sign in (for CLIs that need it) and an edit button. Switch on the ones you want: the model picker in the chat and Team mode use whichever are on.

AgentCan use your connectorsNotes
Claude CodeYesInstall it, run claude once in a terminal and sign in.
Codex CLIYesInstall it (or the Codex desktop app), then run codex login. Models are read from Codex itself.
Gemini CLIYesNeeds an API key (Google AI Studio) or Vertex credentials under Edit > Environment.

Your own CLI or URL modelOptionalSee the next two articles.

Install a CLI for me

If a CLI is missing, its card shows Install for me. You first see exactly what will run and where it comes from, and you must confirm before anything is downloaded.

Which agent for which job

  • For questions about your data, pick an agent that can use connectors.
  • A text-only agent can still answer from the conversation, and can work as a Team helper when the lead gives it the data (Team mode).
Tip

After adding an agent, press Test on its card. It confirms that the model answers before you rely on it.
