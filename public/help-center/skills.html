Skills

Instruction packs the assistant loads only when a question needs one, so they cost nothing until used.

What skills are

Skills are instruction packs. The assistant sees a short list and asks for the skill it wants, so a skill costs nothing until it is used. Skills for a specific software, such as ERPNext or Tally, come from Techlogica and only when this company uses that software.

Turn skills on or off, and write your own

  1. Open Settings > AI > Skills.
  2. Switch a skill on to let the assistant load it when a question needs it. Most are not loaded by default.
  3. Press Add skill to write your own: a name, a description and the instructions. A skill you write stays on your computer.
  4. Use Reset on a built-in skill to restore its original text.

The page can also import the finance and small-business skills of Claude plugins installed on this computer; they arrive switched off.

Where skills are used

  • In chat: type / to choose one (Skills in chat).
  • Per agent: the Skills tags on each agent card (What each agent can use).
  • Automatically: the router offers only the skills that fit the question (How the assistant chooses skills).
